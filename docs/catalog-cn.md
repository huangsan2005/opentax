## 典型组合速查（潜在管线素材）

- 做生意：增值税 + 企业所得税 + 城建税 + 印花税 → 已有 `engineering_to_owner` 系列管线
- 普通人：个税 + 契税 + 车辆购置税 + 车船税 + 印花税 → **待建"个人购车/购房"管线**（补齐契税+车辆购置税后即可）

## 贡献指引

1. 任选上表 ❌/⚠️ 税种，查到**现行有效的官方文号**（法律/条例/财税文/公告）
2. 照抄 `data/rules/cn/*.yaml` 现有结构写新表，文号+生效区间必填
3. `tests/test_golden.py` 加锚点（官方算例/申报表/公式复算三选一）
4. `python run_tests.py` 全绿 → PR
5. 优先顺序建议见 README 路线图：车辆购置税 → 契税 → 房产税 → 印花税全目录 → 车船税
